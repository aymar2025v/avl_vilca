DIAGRAMAS DE FLUJO (PlantUML) - Practica 10 AVL
================================================
Como verlos en VS Code:
  1. Instalar la extension "PlantUML" (jebbs.plantuml). Necesita Java instalado.
  2. Abrir un archivo .wsd y presionar Alt+D para ver la vista previa.
  3. Para exportar a imagen: Ctrl+Shift+P -> "PlantUML: Export Current Diagram".

Convenciones de color:
  Verde  = se crea un objeto o una variable
  Rojo   = se destruye un objeto o una variable
  Nota amarilla = estado de la memoria o explicacion
Cada paso indica el numero de linea del archivo fuente (avl.h o avl_python.py).
